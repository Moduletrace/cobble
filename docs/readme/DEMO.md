## Shot list

Target 12 to 18 seconds, 960px wide, loop, no audio.

1. **0.0s** The rail. Coordinator at top, four workers below with different
   faces. Mouse hovers one, its status line reads "working".
2. **2.5s** Cut to the chat. You type: "Check whether the staging site still
   returns 200 and open a PR if the footer link is broken." Send.
3. **4.5s** The coordinator delegates. Two worker faces go to "working" in the
   rail at the same time.
4. **6.5s** Cut to the live computer view. Chrome is open, the bot is scrolling
   the staging site. The cursor moves on its own. Terminal panel beside it shows
   curl output.
5. **10.0s** The bot hits a login wall. Face flips to "needs you". Card appears
   asking to take over. You click, type the password, hand it back.
6. **12.5s** The bot finishes. PR link appears in chat. Worker faces go to
   "done".
7. **15.0s** Pull back to the rail. Whole crew idle, everything green, one line
   of summary text.

That sequence is the entire product in one loop: delegate, parallel work, a real
browser, a human handoff, a shipped artifact. Do not replace it with a
screenshot carousel.
